# Flow 销售订单操作说明

适用入口：**Flow、销售助理**。订单由导入工具统一预检和创建，使用当前客服账号的业务权限。

业务顺序：**确定客户档案 → 建好需要的客户贴纸物料 → 创建销售订单**。普通商品不需要客户贴纸时可直接开单。

## 客服操作四步

1. **说清需求**：客户、商品和数量；需要客户贴纸时一并说明。例如：“给 Driven25 开销售单，山东绿方、灰方、蓝方各 120 颗，粉方 40 颗，配对应数量的客户贴纸。”
2. **系统自动配对并预检**：识别当前客服、客户专属价格、商品、对应贴纸、地址及已配置税费。商品与客户贴纸同时出现在一笔订单时，助手根据上下文、型号、颜色、版本、数量建议组合，不要求固定话术。只有资料缺失或匹配有歧义时才集中询问。预检不保留组合档案或订单。
3. **整体审核，批准一次**：核对完整中文摘要及批准卡片。正确就批准；有误就拒绝并说明需要修改的内容，修改后重新预检和审核。自动填写的内容同样需要审核，无需另发一遍“确认”再批准。
4. **查看结果**：批准后复用或创建需要的销售组合，保存销售订单草稿并返回真实链接。失败会说明原因及应补充的内容，本次组合和订单写入一起回滚。

## 自动默认值

| 项目 | 默认规则 |
| --- | --- |
| 销售员 | 当前登录客服所关联的有效销售员，销售贡献 100%；不再询问本人邮箱或姓名 |
| 交货截止 | 开单当天起第 7 个自然日，当日 23:59 前，以系统业务时区为准 |
| 发货仓库 | 大坪仓库 - LEYA |
| 配套客户贴纸 | 每件商品配一张，售价统一 0 元；型号或版本有多个合理候选时才需要选清楚 |
| 独立交付贴纸 | 可指定单独交付、备用或整单只送贴纸，售价同样为 0 元；审核提醒，不强制搭配商品 |
| 客户贴纸组合 | 只为实际需要配对的商品创建或复用；已有相同商品、贴纸及比例的组合直接复用，未提贴纸不创建组合 |
| 贴纸定制服务 | 本次已确认提供的服务必须列行；免费也显示服务名称、数量和0元，收费按约定金额。复用旧贴纸不自动再列定制服务 |
| 价格及币种 | 按客户和系统原生价格规则计算；明确指定本单价格时按指定值预检 |
| 保存方式 | 销售订单草稿；不提交订单、不扣库存、不生成收款 |

仓库、交期、商品与贴纸数量等可提出修改，最终以审核摘要为准。销售员关联缺失或冲突时会明确报错，不能猜测或改用客户负责人。

## 组合规则

例如：“山东绿方 120 颗，Driven25 绿方贴纸 120 张”，助手可直接建议 **山东绿方 + Driven25 绿方 v1 贴纸，120 组**。销售单按组合展示，价格沿用巧克粉的售价，贴纸为 0 元；审核卡必须展示配对、数量和“复用／新建”。

- 组合采用原生销售组合，组成商品与贴纸分别管理库存，组合自身不另建库存。
- 一种商品配一种贴纸，每件商品配一张；原始数量不一致时，先明确需要组合的数量和独立交付的剩余数量，不擅自增减数量。
- 同一商品配不同贴纸时拆为对应组合行；重复商品行不会自动合并。
- 明确“备用”“单独发”“不用贴”的贴纸保持独立；未要求贴纸的商品保持普通商品。
- 贴纸售价为 0 不代表成本为 0。采购和库存按真实数量与成本记录，财务核算沿用原生规则。

## 审核时看什么

- **客户与收货信息**：客户名称、地址及缺失提醒。
- **商品与贴纸**：组合对应关系、型号版本、数量、商品单价、小计和复用／新建；贴纸明确显示 0 元。普通商品、组合商品、独立贴纸清楚区分，不重复计算金额或数量。
- **独立贴纸提醒**：审核卡片醒目标记独立贴纸，核对客户、型号版本、数量及用途后，在同一张卡片批准一次即可；不会要求再确认一遍或强制添加巧克粉。客户归属、权限及库存物料校验仍正常执行。
- **交货与负责人**：具体截止日期和时区、完整仓库名称、本人销售员及 100% 业绩分配。
- **金额**：币种、商品金额、贴纸金额、已配置税费和订单总额；尚未核定的运费不得当作已包含。

预检方案有效期为 30 分钟。过期或价格、地址等审核内容发生变化时，必须重新预检并审核。重复执行同一已完成方案会返回原订单，避免重复建单；只有明确要求另开一张相同订单时才创建新方案。

独立贴纸示例：“给 Driven25 单独发 1000 张绿方 v1 贴纸。”如果本次向客户收取 USD 100 定制费，应另列该服务费；贴纸仍为 0 元。创建订单不代表库存已到货，后续出库仍需真实贴纸库存和成本。

## 导入工具参数

本次确认提供贴纸定制服务时，传 `customization_services=[{"item_code":"实际服务物料编码","qty":1,"rate":0}]`，不要再把同一服务重复放进 `items`。服务物料必须已存在、启用且为非库存销售物料。`qty` 默认1，`rate` 默认0；收费必须传本单约定单价，不能读取名称里的数字当价格。预检、审核与保存都保留这条服务；服务数量不计入巧克粉或贴纸数量。只复用旧贴纸、没有确认新服务时不传此参数。免费服务行不会生成库存或采购成本，也不会重复扣除已记账投入。

确认前不出批准卡片。首单无论有没有贴纸档案，都要问要不要贴纸、要不要制作服务。复购要问要不要贴纸，并列出仓库现存量和本单需要数量；不够或没有对应贴纸时，同时问制作服务。客服答复后带 `first_order_confirmed=true` 重新预检，卡片只留一行已确认结果。客户名称只差大小写且唯一时直接认定。同一订单里已有“山东绿方”时，后面的“蓝方”按山东中性处理。

商品与贴纸已分别在 `items` 中时，用 `bundle_mappings=[{"product_row":1,"sticker_row":2}]` 指向原始输入行号（从 1 开始）。对应贴纸行会被组合消费，不再重复添加。明确独立贴纸在该 `items` 行传 `standalone:true`。

只输入商品并要求配贴纸时，可继续使用 `include_stickers:true` 或 `sticker_mappings`；部分商品需要贴纸时只传对应 `sticker_mappings`。同一商品行不能由两类映射重复配对。未传映射但已有两类物料时，后端只自动接受型号与实物数量均唯一匹配的行；其余候选由助手结合上下文判断，仍有歧义才询问客服。
