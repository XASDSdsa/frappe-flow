# Flow 采购与开票

每项业务都先自动核对，缺项集中补齐，再显示一次完整审核卡。聊天只显示结果、原因和下一步。默认保存草稿；明确要求提交时，审核卡会注明提交及其影响。可拒绝修改后重审。重复批准同一方案返回原单。

## 1. 贴纸实际到货入库

告诉助手：“这批贴纸已到货，供应商××，物料××，1000张，采购总价600元，入大坪仓库，审核后提交入库。”助手应明确展示单位成本0.6元、数量1000张和总额600元，不能从客户售价反推成本。

已有采购订单时，提供单号，工具列出剩余可收数量，选择本次实际到货数量。直接收货需要真实供应商、物料、数量和采购单价。采购价币种和仓库都在审核卡中。提交后才真正增加库存并按原生规则记账；供应商付款、采购发票是另外的业务，不会被伪造成已完成。

## 2. 销售开票

告诉助手：“为销售订单××（或出库单××）开票，列出剩余明细。”明确选择本次数量或全部剩余，审核原单价格、税费和预收抵扣。只要草稿就保存草稿；要求提交发票时审核卡明确“提交销售发票”。开票不会再扣一次库存，也不等于再次收款。

## 权限与异常

采购和开票沿用原生创建／提交权限，不扩大客服财务权限。复杂退货、合并发票、序列号／批次、到岸成本等不支持情形会明确说明，转原生界面处理。

审核方案绑定本人及对话，有效30分钟。实际数量、成本、价格或原单变化须重新预检。保存、提交或结果核验失败，本次写入及待发送通知回滚，返回失败步骤和原因，不留下“库存动了但会计没记”的半提交结果。
