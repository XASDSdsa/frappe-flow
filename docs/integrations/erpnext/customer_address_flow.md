# Flow 客户建档：开票与收货地址

客户档案使用原生 Address、Contact、Territory 和首选标记。原生地址类型追加“货代收货”；没有新增客户字段、备注协议或系统审批流程。

## 客服操作

1. 提供客户姓名／公司、客户所在国家、结算币种、联系人以及实际收货地址。说明客户直收或货代代收，普通自然语言即可。
2. 发票地址明确为：与直收地址相同、单独提供，或者暂未提供。没有真实发票地址可以先建档，不能编造城市街道或把货代仓冒充开票地址。
3. Flow 只对缺少的资料集中补问一次。已说“货代仓”“开票地址不知道”等情况直接识别并放进审核卡，不重复问同一问题。
4. 客服在一张中文原生批准卡里整体核对，正确点批准；要修改则拒绝并说明。预检不写资料，批准后保存并回读核验。
5. 成功回复只说明新建／补充／复用结果及真实待补项，不重复整份长摘要。

## 三类地址处理

| 场景 | 地址类型 | 首选送货 | 客户主地址／首选开票 |
|---|---|---|---|
| 客户直收、明确开票同址 | Shipping | 是 | 同一地址 |
| 客户直收、发票地址未知 | Shipping | 是 | 留空 |
| 货代代收、发票地址未知 | 货代收货 | 是 | 留空 |
| 独立发票地址 | Billing | 不自动作为收货 | 使用真实独立地址 |

同址开票必须明确声明，不再把“未提供独立开票地址”当作“允许共用”。货代收货禁止自动共作开票地址。

## 所在地和电话

- 货代客户的地区按客户本人／公司实际所在地生成；只知道马来西亚时使用 Malaysia，不用广州仓地址推断客户在广州。知道实际城市时仍自动匹配／创建对应城市地区。
- 客服明确客户国家未知或暂不提供时，允许先建档：客户销售地区留空，审核卡显示“暂未提供，销售地区留空（待补充）”，不再追问国家，不创建“未知”地区。已有非空地区保留；以后取得实际国家／城市，再通过补充档案填写空白地区。
- 客户国家未知不影响货代仓资料：仓库真实国家、城市、详细地址、有效收货电话仍须提供。若提供客户本人电话，必须带国际区号，不能从该号码推断客户所在国家。
- `mobile_no`、`phone_no`、`email_id` 为客户联系人资料。`shipping_phone` 为收货方电话，`shipping_contact_name` 为收货联系人或仓库名称，保存到原生地址标题。
- 电话统一 `+国家区号 空格 电话号码`。客户电话按客户所在国家解析；收货电话按收货国家解析。
- 货代客户本人电话明确未知时可传 `contact_phone_not_provided=true`，但必须有有效收货电话。审核中显示“客户本人电话未提供”，不会把仓库电话填入客户联系人。
- 邮箱未提供属于提示，不是单独阻止建档的理由。

## 工具接口

原有工具路径与标识保持：`preview_customer_profile` 只读预检；`create_or_reuse_customer_profile` 一次批准保存。

新增工具参数：`address_type`、`billing_address_mode`、`customer_country`、`customer_state`、`customer_city`、`shipping_phone`、`shipping_contact_name`、`contact_phone_not_provided`、`customer_country_not_provided`。

`customer_country_not_provided=true` 仅用于明确国家未知的货代客户，与 `customer_country/customer_state/customer_city` 不能同时填写。若本人电话也未知，同时传 `contact_phone_not_provided=true`；这两个标记仅为工具参数，不新增客户字段。未说明国家是否未知时仍返回缺项，不能默认伪装成客服已确认。

`address_type` 使用 `Shipping` 或 `货代收货`，接受明确中文同义表达。`billing_address_mode` 为 `same_as_shipping`、`separate` 或 `not_provided`。旧调用如果未说明地址用途／开票处理方式，会返回缺项，不继续套用旧默认规则。

独立开票资料通过现有 `billing_address` 对象提供。工具禁止未获授权覆盖原有非空资料、更换首选地址或自动重新分类旧地址；发现用途冲突会准确返回未修改的原因。

## 审核示例

下面是展示示例，不代表已经新建客户：

> 🔵 请审核：新建客户档案（尚未保存）\
> 客户：刘杏生｜币种：CNY\
> 负责人：当前客服｜客户地区：Malaysia\
> 客户电话：未提供\
> **收货方式：货代代收，每次开单核对地址**\
> 收货地址：中国广东省广州市……｜邮编：510545\
> 收货方：运道仓｜电话：+86 ……\
> **发票地址：未提供，本次不设开票地址**\
> 请整体核对后批准一次。

## 实际范围

本次完善客户建档、补充、预检、批准卡及助手说明。并未修改原生开单界面的地址回退规则，也没有新增原生订单审批。后续开单仍须核对真实带出的开票地址和货代收货地址，不能将本次建档分类视为所有业务单据都已自动隔离。
