# 实际采购收货

本流程通过 ERPNext 原生 Purchase Receipt 保存或提交采购收货。只有本批真实到货、数量及成本明确，且用户明确要求提交并在系统整单审核卡片批准后，才实际增加库存及按原生配置产生会计凭证。仅有贴纸档案、采购订单或客户付款不能作为到货依据。

## 操作

1. 提供采购订单号，系统显示精确采购行编号、采购数量、已收货、其他草稿占用、当前最多可收数量、单位、单价和仓库。占用包括采购收货草稿及启用更新库存的采购发票草稿。
2. 明确本批实际合格数量。只接收明确选择的采购行，不自动全收；同物料的不同采购行分别选择。没有采购订单时，提供精确供应商、物料、实际数量及真实正数采购单价。系统原生要求采购订单时仍须先补采购订单。
3. 默认日期为今天，默认仓库为“大坪仓库 - LEYA”；采购来源已有仓库时保留来源仓库。可以明确本次实际仓库、已发生的收货日期及供应商送货/参考号。提供的供应商发票号保存在收货备注，不等于创建采购发票。
4. 预检返回整单摘要：供应商、公司、币种、汇率、实际日期、采购关联、贴纸所属客户、数量、单位、仓库、单价、净额、库存单位估值和原生税费。批准一次后执行；重复调用同一方案返回该方案原单。
5. 默认只保存草稿。明确要求实际到货入库时，`submit=true` 且 `actual_receipt=true`，在同一审核卡片批准后由原生控制器提交库存与会计。草稿保存不增加库存。

客户贴纸沿用现有标准变体及精确旧编码身份规则，必须能唯一确认且有权读取所属客户，必须维护库存、具有正数真实采购单价及原生正数估值。指定客户或来源销售订单时同时核对客户归属。

## 工具参数

`get_purchase_receipt_options(purchase_order="", supplier="", item_codes=None, start=0)` 只读列出当前账号可读的采购订单，或读取精确订单/物料。可收数量不会透露无权读取的草稿名称。明确采购来源时返回 `source_revision`，预检也会冻结当前来源版本，审核期间来源改变须重新预检。

`preview_purchase_receipt(request)` 使用如下结构；未支持字段会明确报错，不会静默丢弃。

```json
{
  "purchase_order": "PUR-ORD-2026-00001",
  "items": [{"purchase_order_item": "精确采购行编号", "qty": 1000}],
  "posting_date": "2026-09-18",
  "supplier_reference": "供应商送货单号",
  "supplier_invoice": "供应商发票号（如已提供）",
  "submit": true,
  "actual_receipt": true
}
```

直接收货使用 `supplier` 和 `items: [{item_code, qty, rate}]`。`rate` 是采购单位的真实单价，原生税费、折扣和单位换算决定最终库存估值。可选 `company`、`currency`、`customer`、`warehouse`；行级可选 `warehouse`、`uom`。公司、币种、税费沿用原生默认及供应商配置；单位只能使用物料已有的明确换算。采购来源行可明确 `rate`，原生“保持与采购订单同价”等规则仍须通过。

`preview_purchase_receipt({"existing_document": "MAT-PRE-2026-00001", "submit": true, "actual_receipt": true})` 审核现有草稿并提交；默认也可仅保存。已有草稿不允许同时传隐藏覆盖参数，先在原生页面修改再重新预检。原单及相关采购来源仍须具备读、写、提交权限，其他草稿占用不包含本草稿自己。

`save_purchase_receipt(preview_token)` 为一次系统整单批准的写工具，使用实际预检令牌；既有单据、并发来源变化、原生校验和账务验证由共同审核执行边界保护。

## 当前边界

退货、拒收、委外、内部调拨、固定资产、批次/序列号、自动上架分仓、后加到岸成本及既有采购发票关联收货，应在对应原生页面补齐真实资料。本工具返回具体原因，不能编造批次、序列号、采购成本或通过零估值放行。标准采购税费模板中的估值费用由原生计算并在摘要展示。

测试覆盖严格参数、数量和成本有限正数、集中补缺、真实到货提交要求、现有草稿无隐藏覆盖、采购行精确匹配、已收及草稿占用、并发数量变化、权限和来源锁定。单元测试不模拟原生库存及总账提交；部署时仍须在真实 Frappe 环境验证预检及原生权限，不创建虚假到货单据。
